# Portfólio Pessoal – Luan

Projeto desenvolvido para apresentação pessoal e portfólio no GitHub.

## O que o projeto faz
- Apresenta informações pessoais e profissionais
- Possui páginas separadas para:
  - Início
  - Sobre mim
  - Projetos
  - Habilidades
- Exibe habilidades técnicas organizadas por categorias
- Mostra projetos desenvolvidos com links para o GitHub
- Aplica animações suaves ao rolar a página

## Tecnologias usadas
- HTML
- CSS
- JavaScript

## O que eu aprendi
- Estruturação de um site multi-páginas
- Organização e reutilização de estilos CSS
- Criação de layouts responsivos
- Uso de animações com Intersection Observer

## Como rodar o projeto
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
